# Chronologie

Les dates antérieures à l'époque moderne sont souvent approximatives ; « c. » indique les meilleures estimations des historiens.

| Date | Événement |
|---|---|
| 762 | Fondation de Bagdad, capitale abbasside |
| c. années 770 | Le matériel astronomique indien du *Sindhind* est traduit à la cour d'al-Mansur (al-Fazari) ; arrivée des chiffres décimaux |
| c. 786–833 | al-Hajjaj traduit les *Éléments* d'Euclide, puis l'*Almageste* de Ptolémée |
| 813–833 | Califat d'al-Ma'mun ; essor de la Maison de la Sagesse ; programmes d'observation à Bagdad et à Damas |
| c. années 820 | L'*Algèbre* et l'arithmétique d'al-Khawarizmi ; le *Zij al-Sindhind* |
| c. 830–870 | Activité des Banu Musa ; l'optique et la cryptanalyse d'al-Kindi ; al-Jawhari sur les parallèles |
| 836–901 | Thabit ibn Qurra : nombres amiables, quadratures de la parabole, préservation des *Coniques* |
| c. 858–929 | Les quarante années d'observations d'al-Battani à Raqqa ; le *Zij sabéen* |
| c. 900 | L'algèbre d'Abu Kamil à coefficients irrationnels |
| 908–946 | Ibrahim ibn Sinan ; élégante quadrature de la parabole |
| 952/953 | al-Uqlidisi à Damas : les plus anciennes fractions décimales |
| c. 960–1000 | Abu al-Wafa consolide les six fonctions trigonométriques ; loi des sinus sphériques (aussi Abu Nasr, al-Khujandi) ; al-Quhi et al-Sijzi sur les constructions par coniques ; Ibn Sahl énonce la loi de la réfraction (984) |
| c. 950–1007 | Maslama al-Majriti apporte l'astronomie orientale à Cordoue |
| c. 1000 | L'algèbre polynomiale d'al-Karaji ; le triangle binomial |
| c. 1007–1009 | Ibn Yunus achève le *Zij hakimite* au Caire |
| c. 1011–1021 | Ibn al-Haytham rédige le *Livre de l'optique* au Caire |
| c. années 1030 | Le *Qanun al-Mas'udi* d'al-Biruni ; géodésie et ombres |
| c. 1070 | L'algèbre des équations cubiques d'Omar Khayyam (Ispahan) |
| 1077 | L'*Explication des difficultés d'Euclide* de Khayyam (parallèles, rapports) |
| 1079 | Réforme du calendrier jalali |
| 1085 | Tolède tombe aux mains de la Castille ; ses bibliothèques commencent à alimenter la traduction latine |
| m. 1085 | al-Mu'taman ibn Hud de Saragosse (théorème de type Ceva dans l'*Istikmal*) |
| c. 1100–1200 | Le siècle de la traduction latine : Adélard de Bath, Robert de Chester (*Algèbre*, 1145), Gérard de Crémone (m. 1187, plus de 70 ouvrages) |
| c. 1120–1150 | Jabir ibn Aflah (Geber) à Séville ; source latine de la trigonométrie sphérique |
| c. 1150 | Le *al-Bahir* d'al-Samawal : division des polynômes, exposants négatifs, démonstrations de type récurrence |
| c. 1170 – c. années 1240 | Fibonacci ; *Liber Abaci* 1202/1228 |
| c. 1135 – c. 1213 | Sharaf al-Din al-Tusi : dénombrement des racines par les maxima, résolution numérique des cubiques |
| c. années 1200 | Maghreb : la combinatoire d'Ibn Mun'im ; la barre de fraction d'al-Hassar déjà en circulation |
| 1258 | Les Mongols prennent Bagdad |
| 1259 | Fondation de l'observatoire de Maragha ; Nasir al-Din al-Tusi le dirige ; Urdi construit les instruments |
| c. 1260–1274 | Le *Quadrilatère complet* de Tusi (la trigonométrie comme science indépendante) et la *Tadhkira* (couple de Tusi) |
| 1256 – c. 1321 | Ibn al-Banna à Marrakech ; le *Talkhis* ; formules combinatoires |
| c. 1300–1319 | al-Farisi : théorie de l'arc-en-ciel ; nombres amiables par factorisation |
| c. 1350–1375 | Damas : les modèles planétaires sans équant d'Ibn al-Shatir ; les tables universelles d'al-Khalili |
| c. années 1420 | Observatoire et madrasa de Samarcande (Ulugh Beg, Qadi Zada, al-Kashi) |
| 1424 | al-Kashi calcule 2π avec 16 décimales |
| 1427 | Le *Miftah al-Hisab* d'al-Kashi : fractions décimales systématiques |
| c. 1437–1449 | Le *Zij-i Sultani* et le catalogue de 1 018 étoiles |
| 1449 | Assassinat d'Ulugh Beg ; dispersion de l'école de Samarcande (Ali Qushji part vers l'ouest, à Istanbul, dans les années 1470) |
| 1412–1486 | al-Qalasadi codifie le symbolisme algébrique maghrébin |
| 1145 / 1543 / 1545 | Jalons de la continuation européenne : l'*Algèbre* latine ; le *De revolutionibus* (avec des modèles identiques à ceux de Maragha) ; l'*Ars Magna* (cubiques résolues arithmétiquement) |
| 1575–1580 | L'observatoire d'Istanbul de Taqi al-Din (contemporain d'Uraniborg de Tycho Brahe) |
| 1585 | Le *De Thiende* de Stevin introduit les fractions décimales en Europe (antériorité d'al-Kashi : 158 ans ; d'al-Uqlidisi : 633 ans) |
| 1594 | Le pseudo-Tusi d'Euclide est imprimé à Rome ; lu plus tard par Wallis, cité par Saccheri (1733), préhistoire de la géométrie non euclidienne |
| 1665 | Le catalogue d'étoiles d'Ulugh Beg est imprimé à Oxford |
| XIXe–XXe s. | L'historiographie moderne redécouvre la tradition : Woepcke, Nallino, Luckey, Kennedy, Saidan, Sabra, Rashed, King, Berggren, Hogendijk, Djebbar |
