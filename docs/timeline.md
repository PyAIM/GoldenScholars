# Timeline

Dates before the modern period are frequently approximate; "c." marks scholarly best estimates.

| Date | Event |
|---|---|
| 762 | Baghdad founded as Abbasid capital |
| c. 770s | Indian *Sindhind* astronomical material translated at al-Mansur's court (al-Fazari); decimal numerals arrive |
| c. 786–833 | al-Hajjaj translates Euclid's *Elements*, then Ptolemy's *Almagest* |
| 813–833 | Caliphate of al-Ma'mun; House of Wisdom flourishes; observational programs at Baghdad and Damascus |
| c. 820s | al-Khwarizmi's *Algebra* and arithmetic; the *Zij al-Sindhind* |
| c. 830–870 | Banu Musa active; al-Kindi's optics and cryptanalysis; al-Jawhari on parallels |
| 836–901 | Thabit ibn Qurra: amicable numbers, parabola quadratures, Conics preservation |
| c. 858–929 | al-Battani's forty years of Raqqa observations; the *Sabian Zij* |
| c. 900 | Abu Kamil's algebra with irrational coefficients |
| 908–946 | Ibrahim ibn Sinan; elegant parabola quadrature |
| 952/953 | al-Uqlidisi in Damascus: earliest decimal fractions |
| c. 960–1000 | Abu al-Wafa consolidates the six trigonometric functions; spherical law of sines (also Abu Nasr, al-Khujandi); al-Quhi and al-Sijzi on conic constructions; Ibn Sahl states the refraction law (984) |
| c. 950–1007 | Maslama al-Majriti brings eastern astronomy to Córdoba |
| c. 1000 | al-Karaji's polynomial algebra; binomial triangle |
| c. 1007–1009 | Ibn Yunus completes the *Hakimi Zij* in Cairo |
| c. 1011–1021 | Ibn al-Haytham writes the *Book of Optics* in Cairo |
| c. 1030s | al-Biruni's *Qanun al-Mas'udi*; geodesy and shadows |
| c. 1070 | Omar Khayyam's algebra of cubics (Isfahan) |
| 1077 | Khayyam's *Explanation of Difficulties in Euclid* (parallels, ratios) |
| 1079 | Jalali calendar reform |
| 1085 | Toledo falls to Castile; its libraries begin feeding Latin translation |
| d. 1085 | al-Mu'taman ibn Hud of Zaragoza (Ceva-type theorem in the *Istikmal*) |
| c. 1100–1200 | Latin translation century: Adelard of Bath, Robert of Chester (Algebra, 1145), Gerard of Cremona (d. 1187, ~70+ works) |
| c. 1120–1150 | Jabir ibn Aflah (Geber) in Seville; Latin spherical trigonometry source |
| c. 1150 | al-Samawal's *al-Bahir*: polynomial division, negative exponents, induction-style proofs |
| c. 1170 – c. 1240s | Fibonacci; *Liber Abaci* 1202/1228 |
| c. 1135 – c. 1213 | Sharaf al-Din al-Tusi: root counting via maxima, numerical solution of cubics |
| c. 1200s | Maghreb: Ibn Munim's combinatorics; al-Hassar's fraction bar already circulating |
| 1258 | Mongols take Baghdad |
| 1259 | Maragha observatory founded; Nasir al-Din al-Tusi directs; Urdi builds instruments |
| c. 1260–1274 | Tusi's *Complete Quadrilateral* (trigonometry as independent science) and *Tadhkira* (Tusi couple) |
| 1256 – c. 1321 | Ibn al-Banna in Marrakesh; *Talkhis*; combinatorial formulas |
| c. 1300–1319 | al-Farisi: rainbow theory; amicable numbers via factorization |
| c. 1350–1375 | Damascus: Ibn al-Shatir's equant-free planetary models; al-Khalili's universal tables |
| c. 1420s | Samarkand observatory and madrasa (Ulugh Beg, Qadi Zada, al-Kashi) |
| 1424 | al-Kashi computes 2π to 16 decimal places |
| 1427 | al-Kashi's *Miftah al-Hisab*: systematic decimal fractions |
| c. 1437–1449 | *Zij-i Sultani* and the 1,018-star catalogue |
| 1449 | Ulugh Beg murdered; Samarkand school disperses (Ali Qushji west to Istanbul, 1470s) |
| 1412–1486 | al-Qalasadi codifies Maghrebi algebraic symbolism |
| 1145 / 1543 / 1545 | Milestones of the European continuation: Latin Algebra; *De revolutionibus* (with Maragha-identical models); *Ars Magna* (cubics solved arithmetically) |
| 1575–1580 | Taqi al-Din's Istanbul observatory (contemporary of Tycho's Uraniborg) |
| 1585 | Stevin's *De Thiende* brings decimal fractions to Europe (al-Kashi's priority: 158 years; al-Uqlidisi's: 633) |
| 1594 | Pseudo-Tusi Euclid printed in Rome; later read by Wallis, cited by Saccheri (1733), prehistory of non-Euclidean geometry |
| 1665 | Ulugh Beg's star catalogue printed at Oxford |
| 19th–20th c. | Modern historiography recovers the tradition: Woepcke, Nallino, Luckey, Kennedy, Saidan, Sabra, Rashed, King, Berggren, Hogendijk, Djebbar |
